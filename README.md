# 回家看看 · 方案 A

按确认的方案 A 平面图建立的家庭装修 3D 基础漫游，支持手机横屏和竖屏。

- 拖动画面看四周；按箭头行走，或点房间名沿通道前往。
- 自动看房约一分钟完成一圈，随时暂停。
- 第一人称眼高1.65米；第三人称人物身高1.65米。
- 尺寸与收纳面板展示各房间的柜体、设备和待核问题。

全部模型、材质与运行组件都随站点提供，无须访问原来的 ChatGPT 网址或外部模型 CDN。

## 尺寸限制

主卧净尺寸3900×3330、次卧3350×3230，床垫均1800×2000毫米。模型采用相同米制比例。净高2650、墙厚和窗高是方案假设，原图右侧进深链尚未闭合。卫生间按图坐便前方约380毫米偏紧，应优先量房确认及调整。这是装修布局交流模型，不作为施工下单依据。

## 发布

GitHub Pages 从 main 分支根目录发布；.nojekyll 关闭额外模板处理。维护 app.js 的交互、scene.js 的模型、storage.js 的说明即可。通过 HTTP 静态服务预览，需要支持 WebGL 2 的浏览器。
